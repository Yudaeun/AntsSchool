# 개인정보처리방침

**개미의 경제학교** (이하 "앱")는 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」을 준수합니다.

**시행일: 2026년 6월 9일**

---

## 1. 수집하는 개인정보 항목

### 직접 수집 (Google 로그인 시)
- 이름, 이메일 주소, 프로필 사진 (Google 계정 기본 정보)

### 서비스 이용 중 자동 수집
- 학습 진도 (완료한 챕터, 학습 카드 열람 기록)
- 퀴즈 결과 (정답/오답 내역, 오답노트)
- 게임화 데이터 (레벨, 경험치, 배지, 출석 스트릭)
- 북마크한 뉴스 목록

### 광고 서비스(Google AdMob)를 통한 수집
- 기기 식별자(광고 ID), 기기 정보, 앱 사용 데이터
- Google의 개인정보처리방침이 적용됩니다: https://policies.google.com/privacy

---

## 2. 개인정보 수집 및 이용 목적

| 목적 | 이용 항목 |
|---|---|
| 회원 식별 및 로그인 | 이름, 이메일, 프로필 사진 |
| 기기 간 학습 데이터 동기화 | 학습 진도, 퀴즈 결과, 레벨/배지/스트릭, 북마크 |
| 맞춤형 학습 서비스 제공 | 오답 기록, 학습 이력 |
| 광고 제공 | 광고 ID, 기기 정보 (Google AdMob 처리) |

## 3. 개인정보 보유 및 이용 기간

- **회원 탈퇴 시**: 즉시 삭제
- **서비스 미이용 후 1년 경과 시**: 자동 삭제 (사전 안내 후)
- **관계 법령에 따른 보존 항목**: 해당 법령에서 정한 기간

## 4. 개인정보의 제3자 제공

앱은 원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다.  
단, 아래의 경우는 예외입니다.

- **Google Firebase Authentication**: 로그인 처리 목적
- **Google AdMob**: 광고 제공 목적
- **법령에 의한 요청**: 수사기관의 적법한 요청이 있는 경우
